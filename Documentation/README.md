# Documentation Map

This folder keeps project documentation and planning records separate from the
plugin source code.

- `API_KEYS.md` — per-server TMDb and Watchmode credential setup, safe storage,
  quota tracking, and rotation.
- `CHANGELOG.md` — chronological record of user-visible changes.
- `JELLYFIN_10.11.11_COMPATIBILITY_AUDIT.md` — source-level compatibility audit
  against the active Jellyfin server version.
- `project-goals.txt` — product scope, implementation status, and acceptance behavior.
- `goal-testing.txt` — live-server checklist, environment record, and results log,
  including the test-build record through 0.1.0.66 and the 1.0.0 release
  preparation results.

The current public guide covers the full current dashboard: Main Settings;
Network and Provider (including the Provider and Network Library Overview);
Genres and Keywords (including its dedicated Library Overview); Collections;
Cast and Crew; more like this; Production Companies and Countries; Ratings;
Spoken Languages and Translations; and Scan as the last secondary-row tab.

The public project guide is [README.md](../README.md).
