# 1.0.0.1

This Jellyfin `10.11.11` catalog image-cache repair creates a fresh local
plugin manifest so Jellyfin downloads and displays the published Media Tagging
Manager photo. It contains only `Jellyfin.Plugin.MediaTaggingManager.dll` and
the license—never API keys, Jellyfin configuration, backups, logs, cached
source data, NFO files, or media data.

Use the repository's `manifest.json` URL in **Dashboard → Plugins →
Repositories** to install or update the plugin.

See the [project guide](../../README.md),
[compatibility audit](../../Documentation/JELLYFIN_10.11.11_COMPATIBILITY_AUDIT.md),
and [recorded validation results](../../Documentation/goal-testing.txt).
