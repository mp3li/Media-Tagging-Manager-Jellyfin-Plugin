# 1.0.0.2

This Jellyfin `10.11.11` release moves the Scan tab immediately after Main
Settings so the full selected-library scan is easier to find. It contains only
`Jellyfin.Plugin.MediaTaggingManager.dll` and the license—never API keys,
Jellyfin configuration, backups, logs, cached source data, NFO files, or media
data.

Use the repository's `manifest.json` URL in **Dashboard → Plugins →
Repositories** to install or update the plugin.

See the [project guide](../../README.md),
[compatibility audit](../../Documentation/JELLYFIN_10.11.11_COMPATIBILITY_AUDIT.md),
and [recorded validation results](../../Documentation/goal-testing.txt).
