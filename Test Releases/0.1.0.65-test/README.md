# 0.1.0.65-test

This public Jellyfin `10.11.11` catalog-install test build is not a stable
release. It contains only `Jellyfin.Plugin.MediaTaggingManager.dll` and the
license—never API keys, Jellyfin configuration, backups, logs, cached source
data, NFO files, or media data.

It moves the focused Provider and Network Library Overview, its filters,
manual edits, and Unknown Providers and Networks section to the bottom of
**Network and Provider Settings**. The previous separate **View and Edit Tags**
tab is removed. **Genres and Keywords Settings** now has its own collapsible,
filterable, editable Library Overview, and **Scan** is the final secondary-row
tab.

Record live results in [goal-testing.txt](../../Documentation/goal-testing.txt).
